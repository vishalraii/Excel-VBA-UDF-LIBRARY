# Excel-VBA-UDF-LIBRARY
Welcome to the Excel VBA Custom Functions Toolkit! This repository contains a collection of powerful, production-ready User-Defined Functions (UDFs) designed to supercharge your Excel workflows, automate repetitive data manipulation, and solve complex modeling challenges that standard Excel formulas cannot handle alone.
UDF Covered	Purpose & Capabilities

VBA_TN	
Text/Number Extractor: Extracts purely text or numbers from cells containing mixed, alpha-numeric data.
VBA_LOOKUP	
Intra-Workbook Lookup: Performs advanced cross-sheet lookups dynamically across the entire active workbook.
VBA_ALL_LOOKUP	
Global Lookup: Executes global cross-workbook lookups across all currently open Excel files.
VBA_COLORSUM	
Format-Based Analytics: Sums values in a designated range based on the cell's background color.
VBA_TOP_N_STAT	
Top-Tier Statistics: Calculates advanced metrics and statistics on the Top-N values within a specific range.
VBA_TextCleaner	
Data Sanitization: Automatically cleans and standardizes messy, unformatted, or corrupted text strings.
